# ArgonShield

## Overview
I am trying to make a whole-home internet/network defense setup. I did this to create stronger defense against hacking and spyware, privacy from outside surveillance, cleaner internet, and better WIFI control.

## Objective
Is it possible to create a more secured whole-home network?

## Environment
- Home / physical everyday use on multiple smart devices.
